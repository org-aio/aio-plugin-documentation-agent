# 本地管理页示例

此功能提供普通 CRUD 和左树右表两个页面，使用同一份中立库存示例数据。页面只读写当前浏览器的 `localStorage`，没有后台接口或身份认证，不可用于存放敏感业务数据。

- `model.mjs`：独立于 Vue 的不可变数据操作、查询分页、分类约束和缓存校验；`model.d.mts` 提供类型契约。
- `store.ts`：按宿主 `appConfig.appId` 隔离存储，存储键为 `${appId}:examples:v1`。先保存成功再更新页面状态；保存失败会保留原状态并显示错误。
- `RecordsTable.vue`：共享查询表单、分页表格和新增编辑弹窗。
- `CategoryTree.vue`：分类筛选、选中、新增、重命名和受约束删除；父分类计数与过滤均包含子分类。
- `messages.ts`：页面文案，由宿主的 `@/locales` 装配。

所有业务操作在模型边界重新校验。编码不区分大小写判重；同一父分类下名称不可重复；存在子分类或关联记录时禁止删除分类。

在生成的前端项目根目录运行：

```sh
node --test src/features/examples/model.test.mjs
```

接入真实业务时，应以生成的 API 和元数据替换本地示例模型，并由宿主补齐服务端校验、权限及并发控制。
